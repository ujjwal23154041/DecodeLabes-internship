# 🤖 Rule-Based AI Chatbot

A simple Rule-Based AI Chatbot built using Python.  
This chatbot responds to predefined user inputs using if-else logic and runs continuously until the user exits the program.

---

# 📌 Project Overview

This project is designed for beginners to understand the basics of Artificial Intelligence concepts using simple programming logic.

The chatbot can:
- Respond to greetings
- Answer simple questions
- Show date and time
- Perform basic calculations
- Motivate users
- Exit gracefully

---

# 🚀 Features

✅ Greeting responses  
✅ Continuous conversation loop  
✅ Date and time feature  
✅ Simple calculator  
✅ Motivational messages  
✅ Help command  
✅ Exit command  
✅ Beginner-friendly code
